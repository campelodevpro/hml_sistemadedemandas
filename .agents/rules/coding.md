# Regras de desenvolvimento

1. Validar toda entrada como nao confiavel.
2. Usar consultas parametrizadas.
3. Preferir mudancas pequenas e reversiveis.
4. Escrever teste de aceitacao antes ou junto do codigo.
5. Nao adicionar dependencias sem verificar existencia, mantenedor e historico.
6. Registrar regras e exemplos antes da implementacao.
7. Atualizar docs e estado no mesmo commit.
