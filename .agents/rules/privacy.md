# Privacidade

1. Coletar somente dados necessarios.
2. Usar dados sinteticos em desenvolvimento e testes.
3. Nao registrar senhas, tokens ou dados pessoais em logs.
4. Mapear base legal, finalidade e retencao no dicionario de dados.
5. Restringir indicadores de desempenho conforme unidade, setor e perfil.
6. Evitar expor comparacoes individuais para quem nao precisa delas.
7. Permitir correcao e revisao dos dados conforme as regras do projeto.
