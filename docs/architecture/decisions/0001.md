# ADR 0001: Base inicial do Sismon

## Status

Aceita para scaffolding. Decisoes de frontend e detalhes de deploy ainda pendentes.

## Contexto

O projeto precisa de um portal visual para uma equipe pequena, com muitos chamados e projetos concorrentes, executado inicialmente na maquina do responsavel e usando ferramentas gratuitas.

## Decisao

Usar Python com Django no backend, PostgreSQL como banco, Django Templates com HTMX e Bootstrap 5 na interface, e JavaScript somente quando necessario. A arquitetura sera um monolito modular, com Django Authentication e Django ORM. Calcular os indicadores no proprio banco e renderizar no portal. Restringir acesso no servidor por perfil, unidade, setor, projeto e demanda. Executar inicialmente em Windows e localhost.

## Consequencias

O primeiro ambiente sera simples de manter. O modelo deve evitar dependencias de BI externo. A forma de acesso de outros dispositivos e a tecnologia visual serao definidas antes do codigo.
