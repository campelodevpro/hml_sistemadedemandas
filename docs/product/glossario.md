# Glossario

| Termo | Significado no Sismon |
|---|---|
| Demanda | Necessidade de trabalho que pode conter uma ou mais tarefas |
| Tarefa | Unidade executavel de trabalho dentro de uma demanda ou projeto |
| Atividade | Trabalho individual que pode ser solto ou ligado a um projeto |
| Projeto | Conjunto organizado de demandas e tarefas com objetivo e prazo |
| Backlog | Lista de itens ainda nao iniciados no fluxo oficial |
| Rascunho | Item incompleto, privado e fora do fluxo oficial |
| Quadro | Visao visual das tarefas por etapas |
| Unidade | Agrupador organizacional de equipes e pessoas |
| Setor | Subdivisao organizacional com escopo de acesso |
| Cycle time | Tempo entre o inicio e a conclusao de uma tarefa |
| Throughput | Quantidade de tarefas concluidas em um periodo |
| Capacidade | Horas disponiveis para assumir trabalho |
